# Два Престола (TwoThrones)

Вертикальная стратегия для Android.
Свет vs Тьма. Свои государства в союзе. Дипломатия, восстания, религии, усталость от войны.
Без доната.

---

## Усталость от войны

Пока страна в войне, каждый год растёт **усталость от войны** (0–100).

| Уровень | Эффект |
|--------|--------|
| 0–25 | Норма |
| 26–50 | −счастье, чуть дороже содержание армии |
| 51–75 | −стабильность, выше шанс восстаний, армия слабее |
| 76–100 | Сильный штраф к бою, риск отказа воевать |

Снижается: мир, годы без боёв, реформы-праздники.

## Релизный костяк

- Лобби: Играть, магазин, профиль
- Мета: серебро / золото / кристаллы
- В матче: **Деньги**
- Свет / Тьма, 6 правителей, 10 типов армии
- Дипломатия с торгом; отношения 0–100; признание (без него потолок 50)
- Новости + год (старт 100) + названия войн/договоров
- Шпионы, восстания→страны, реформы, религии %, усталость от войны

**Правители:** Тьма — Карл II, Наполеон, Чингисхан · Свет — Леопольд I, Кутузов, Невский
